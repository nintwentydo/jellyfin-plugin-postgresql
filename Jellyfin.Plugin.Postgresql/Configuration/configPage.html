PostgreSQL

Jellyfin selects its database before plugins load, so this provider is not configured from this page. Settings come from config/database.xml, with environment variables as a fallback.

database.xml

<?xml version="1.0" encoding="utf-8"?>
<DatabaseConfigurationOptions>
  <DatabaseType>PLUGIN_PROVIDER</DatabaseType>
  <CustomProviderOptions>
    <PluginName>PostgreSQL</PluginName>
    <PluginAssembly>Jellyfin.Plugin.Postgresql.dll</PluginAssembly>
    <ConnectionString>Host=db;Port=5432;Database=jellyfin;Username=jellyfin;Password=CHANGEME</ConnectionString>
  </CustomProviderOptions>
  <LockingBehavior>NoLock</LockingBehavior>
</DatabaseConfigurationOptions>

Environment variables

Used only when ConnectionString is empty.

  • POSTGRES_HOST, POSTGRES_PORT, POSTGRES_DB
  • POSTGRES_USER, POSTGRES_PASSWORD
  • POSTGRES_SSLMODE
  • POSTGRES_COMMAND_TIMEOUT

The PostgreSQL client tools (pg_dump and psql) must be on PATH; Jellyfin backs the database up before applying schema migrations.
