This prerelease pairs PostgreSQL plugin **1.1.3.0** with custom **Jellyfin 13.0.0**, fixing UserData reattachment, orphan cleanup and transactional restores with generated IDs.

Docker (`linux/amd64`, `linux/arm64`): `docker pull ghcr.io/nintwentydo/jellyfin-postgres:1.1.3.0-jf13-custom`.

Review the [known limitations](https://github.com/nintwentydo/jellyfin-plugin-postgresql/blob/codex/custom-core-restore/docs/docker.md#known-limitations) and [backup guidance](https://github.com/nintwentydo/jellyfin-plugin-postgresql/blob/codex/custom-core-restore/docs/operations.md).
